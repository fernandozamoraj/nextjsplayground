This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Pages

| Route | Description |
|---|---|
| `/shooter` | First-person 3D shooter — see [SHOOTER.md](SHOOTER.md) |
| `/shapeworld` | Free-roam 3D world (same engine, no objectives) |
| `/sudokuSolver` | Backtracking sudoku solver with interactive 9×9 grid |
| `/towersOfHanoi` | Step-through visual Tower of Hanoi solver |
| `/ammortizationCalculator` | Loan amortization schedule calculator |
| `/investmentCalculator` | Investment growth calculator |
| `/calendar` | Interactive calendar |
| `/todoapp` | Simple todo list |
| `/students` | Student records demo |
| `/typingGame` | Typing speed game |

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
